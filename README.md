**Project: FNB Review Analyzer – Sentiment Analysis Dashboard**

Developed an interactive Business Intelligence dashboard to analyze customer reviews for FNB across multiple branches and provinces. 
The solution provides:

**Key Metrics**: Total reviews (6,437), average rating (4.0 stars), sentiment coverage across 8 provinces.

**Sentiment Analysis**: Categorized comments into positive, neutral, and negative, with keyword frequency insights.

**Geographical Insights**: Visualized sentiment distribution by province and branch location using maps.

**Branch Performance**: Identified top and bottom performing branches based on average ratings.

**Tools Used**: QlikSense/QlikView, SQL, and Python for data processing and visualization.

**The dashboard enables stakeholders to monitor customer feedback trends, identify service improvement areas, and enhance customer experience strategies.**
